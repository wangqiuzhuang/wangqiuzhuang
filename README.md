    * *비즈니스 확장성:* 수많은 다운스트림 시스템과 복잡한 비즈니스 시나리오가 얽힌 상황에서, 새롭게 연동되는 제품들을 템플릿화 및 설정화(Configuration)하여 신속한 인프라 진입을 보장함[cite: 3].
    * *관측 가능성(Observability):* 계정 시스템의 핵심 지표 모니터링 대시보드가 부재했던 문제를 해결하기 위해, 비즈니스 영역(인증, 대출, 상환 등 변동 트렌드)과 기술 영역(CPU, I/O, 메모리, QPS, TPS, 테이블 용량 등)을 아우르는 핵심 통합 모니터링 대시보드를 전면 구축함[cite: 3].
    * *성능 정체(Slow Elements) 거버넌스:* 단일 테이블 데이터가 3억 건을 초과하고 배치 구동 시 CPU 점유율이 100%에 달하는 고질적 병목을 해결하기 위해 매시브 튜닝 태스크를 전개함[cite: 3].
* **안정성 및 최적화 아키텍처 작업 내용:**
    * **Slow SQL 타파:** 원인 포지셔닝 + 딥 인덱스 최적화 + 비즈니스 로직 분해 + 복잡 코드 리팩토링의 종합 솔루션을 적용하여 대대적인 전수 조사를 감행함[cite: 3].
    * **느린 배치(Batch) 리팩토링:** 동시성 제어 조정, 비동기 메시지 디커플링, 물리 머신 인스턴스 분할 등을 통해 분산 배치 엔진을 업그레이드하여 성능 저하 문제를 완전히 해결함[cite: 3].
    * **느린 API 최적화:** 읽기/쓰기 분리(Read-Write Splitting) 아키텍처, 비동기 처리, 래피드 피크 셰이빙(Peak Shaving), 루프 쿼리 제거 전략을 사용하여 인터페이스 병목을 타파함[cite: 3].
    * **마스터-슬레이브 동기화 지연 해소:** 비동기화 중공축 리팩토링, 동적 스레드 풀 조정 및 데이터베이스 분할 설계를 통해 DB 레이어의 I/O 서지를 완전히 평탄화함[cite: 3].
* **프로젝트 성과:**
    * **극대화된 튜닝 성과:** 핵심 DB의 Slow SQL 수를 23,000+ 건에서 100+ 건으로 급감(99% 감소)[cite: 3]. 핵심 API의 TP99 응답 시간을 3,000ms에서 200ms 이하로 단축(93% 감소)[cite: 3]. DB 마스터-슬레이브 지연 시간을 피크 시 4,000초에서 10초 이내로 단축(99.7% 감소)[cite: 3]. 핵심 일마감 배치 가동 총 시간을 평균 50% 단축함[cite: 3].
    * **엔지니어링 생산성 폭발:** 신규 채널 및 제품 연동에 투입되는 공수 비용을 기존 15 Man-Day에서 3 Man-Day로 대폭 절감[cite: 3]. 프로젝트 인도 후 전체 버그 수 80% 감소[cite: 3]. 신규 비즈니스 API 연동 개발 기간을 50% 단축함[cite: 3].

### 고동시성 분산 융자 게이트웨이 및 핵심 시스템 업그레이드 (메이리 금융)
*2018.07 - 2019.08*[cite: 3]  
**역할:** 백엔드 개발 엔지니어[cite: 3]  
* **프로젝트 배경:** 본 플랫폼은 메이리 금융의 핵심 자금 흐름 분배 아키텍처임 (총 개발 인원 286명)[cite: 3]. 대외 게이트웨이(Mgateway), 내부 공용 자금 게이트웨이(Bgis), 분산 스케줄링 모듈(Mjob), 자산 백엔드(Mac), 프론트엔드 운영 시스템(Mface) 등 7개 핵심 시스템을 유지보수하며 자동차 금융, 요우용분기, 현금 대출 등 3대 주선 비즈니스를 정착시키고 백억 대의 자금 흐름을 안정적으로 방어함[cite: 3].
* **핵심 기여 및 수행 내용:**
    * **게이트웨이 아키텍처 표준화 설계:** 대외 게이트웨이(Mgateway) 및 내부 공용 자금 게이트웨이(Bgis)의 온라인 개발 및 표준 연동을 주도함[cite: 3]. 인터페이스를 추상화 및 재사용하여 주요 은행 및 P2P 자금사의 계좌 개설, 사전 심사, 블랙리스트 조회, 청구, 상환 계획 조회, 중도 상환 등 전 단계 금융 프로세스를 모듈화함[cite: 3].
    * **Redis 기반 동적 설정화 리팩토링:** 비즈니스 상수가 변경될 때마다 시스템 배포가 빈번하게 일어나던 리스크를 인지하고, Redis 기반의 동적 설정 센터를 구축함[cite: 3]. 규칙 및 채널 스위치 등을 동적 설정 정보로 변환하여 불안정한 프로덕션 배포 횟수를 대폭 축소함[cite: 3].
    * **고동시성 배치 스케줄링:** 공용 배치 타이머 시스템(Mjob)을 고도화하여 각 서비스의 이벤트를 소비하고 타이머 작업을 설정화함[cite: 3]. 스레드 및 작업 가중치를 합리적으로 분배하여 고동시성 상황에서의 성능 병목을 해소함[cite: 3].
* **프로젝트 성과:**
    * **프로세스 정립 및 품질 향상:** 10명의 개발 팀 내에 표준 엔지니어링 파이프라인(기술 설계서 작성 -> 크로스 팀 디자인 리뷰 -> 코드 리뷰 -> 자동화 테스트 이관 -> 그레이스케일 배포)을 강력히 실행하여 온라인 코드 결함률(Lines-of-Code Bug Rate)을 전년 대비 85% 감소시킴[cite: 3].
    * **설정화 수익 및 인도 효율:** Redis 동적 설정 센터 도입으로 시스템의 불필요한 배포 빈도를 70% 이상 낮췄으며 설정 오류로 인한 프로덕션 장애율 0%를 달성함[cite: 3]. 신규 자금사 채널 연동 주기를 기존 10-15일에서 4-5일로 단축(생산성 60%+ 향상)함[cite: 3]. 프로젝트 지연율을 기존 25%에서 3% 이내로 방어함[cite: 3].

### 바이롄 쇼핑몰(Bailian Mall) B2C 플랫폼 개발 프로젝트
*2017.04 - 2018.06*[cite: 3]  
**역할:** 주니어 개발 엔지니어[cite: 3]  
* **프로젝트 배경:** Dubbo 및 ZooKeeper 인프라 하의 SOA 분산 배포 아키텍처를 채택한 대규모 종합 B2C 커머스 플랫폼 구축 프로젝트[cite: 3]. 회원 서비스, 주문 처리, 상품 검색, 전시 및 백엔드 관리 모듈을 포괄함[cite: 3].
* **핵심 기여 및 성과:**
    * Shiro 기반의 로그인 권한 제어를 구현하고, Redis 클러스터 + JSONP 기반의 SSO(단일 로그인) 시스템을 구축하여 멀티 사이트 통합 인증을 지원함(로그인 성공률 99.9% 달성)[cite: 3].
    * SolrCloud 기반의 상품 검색 모듈을 개발하여 다차원 필터링 및 퍼지 쿼리를 지원했으며, 검색 응답 시간을 200ms 미만으로 제어하고 검색 정확도 95%를 달성함[cite: 3].
    * Freemarker를 활용해 상품 상세 페이지를 정적(Static) 파일로 생성하고, Nginx의 동정 분리(Dynamic-Static Separation) 설정을 적용하여 페이지 로딩 시간을 1.2초에서 300ms로 대폭 단축함[cite: 3].
    * Redis를 적용하여 메인화면 배너, 장바구니 등 핫데이터 캐싱을 구현하여 DB 접근 압력을 60% 줄이고 시스템 지원 QPS를 3배 향상시킴[cite: 3]. 론칭 첫 달 거래액 2,000만 위안 돌파에 기여함[cite: 3].
